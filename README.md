❌⭕ Tic Tac Toe Game (X & O)

A simple Tic Tac Toe game built with React.

📌 Description

This project is a classic X & O (Tic Tac Toe) game where two players take turns playing on a 3×3 board.
The game automatically detects wins, draws, and prevents invalid moves.

🚀 Features

Two-player gameplay (Circle ❍ vs Cross ✖)

Automatic win detection

Draw detection when the board is full

Prevents playing on occupied cells

Prevents playing after the game ends

Clean and simple UI

🛠️ Built With

React

JavaScript (ES6)

useState

useEffect

CSS

🧠 Game Logic

The game board is stored in a 9-cell array.

Winning conditions are checked after every move.

The game stops automatically when a player wins or when a draw occurs.
